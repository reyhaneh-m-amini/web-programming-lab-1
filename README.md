# Meet Daia - Portfolio Website

# 1. Theme
The theme of this project is a personal showcase portfolio dedicated to my beloved cat named **Daia**. The website presents her personality, the things she likes and some services that she offers.

# 2. File Organization
The project only uses HTML5

```
daia_portfolio/
├── index.html        # Home page and introduction
├── about.html        # About page
├── services.html     # Services & talents page
├── contact.html      # Contact form 
├── README.md         # Documentation explaining theme, structure, and challenges
└── assets/           # Folder containing project media
    ├── image1.jpg    
    ├── image2.jpg    
    └── image3.jpg    
```


## 3. Challenges Faced
